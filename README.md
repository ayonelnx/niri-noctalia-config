# Niri Noctalia config
## Установка (Русский)
**Установка зависимостей:** sudo pacman -S niri noctalia dolphin kitty firefox

**Конфиг:** Создайте каталог ~/.config/niri/ и переместите файл **config.kdl** в созданный вами каталог.

**Запуск:** Выйдите из вашей текущей сессии (не важно, какой у вас DE/WM) и зайдите в Niri.

**Примечание:** Редактировать мониторы вы сможете только сами или через ИИ.

## Installation (English)
**Installing dependencies:** sudo pacman -S niri noctalia dolphin kitty firefox

**Config:** Create the directory ~/.config/niri/ and move the **config.kdl** file to the directory you created.

**Launch:** Log out of your current session (no matter which DE/WM you have) and log in to Niri.

**Note:** You can only edit monitors manually or through the AI.
